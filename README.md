# PicoPin

Windows 用の画面キャプチャ・注釈ツールです。**インストール不要・単一ファイル・約 1MB**。

> このリポジトリは**配布専用**です。完成品の `PicoPin.exe` だけを置いています。ソースコードは含まれません。

## ダウンロード

**[→ 最新版をダウンロード](../../releases/latest)**

`PicoPin.exe` をダウンロードして、好きな場所に置いてダブルクリックするだけです。
インストール不要、管理者権限も不要、レジストリも汚しません。消したいときはファイルを削除するだけです。

### 起動時に警告が出たら

「**Windows によって PC が保護されました**」と出ることがあります。
個人開発の署名なしアプリには必ず出る警告で、ウイルスではありません。

1. 「詳細情報」をクリック
2. 「実行」をクリック

## できること

- 範囲・ウィンドウ・全画面のキャプチャ（ホットキー対応）
- 撮った画像の一覧（履歴）
- 注釈エディタ — 矢印・枠・ペン・文字・番号・ぼかし（モザイク代わり）
- **描いた注釈をあとから編集し直せる**
- トリミング、キャンバスサイズ変更、画像の貼り込み
- 画面録画（MP4）
- アプリ内から自動更新

## 動作環境

Windows 10 / 11（64bit）。追加のランタイムは不要です。
