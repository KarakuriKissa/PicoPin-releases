# PicoPin

PicoPin は Windows 用の画面キャプチャ・録画ツールです。撮影した画像や動画を一覧で確認し、編集・変換できます。

## ダウンロードと起動

[最新版の PicoPin.exe をダウンロード](https://github.com/KarakuriKissa/PicoPin-releases/releases/latest/download/PicoPin.exe)し、好きなフォルダに保存して起動してください。インストールは不要です。起動後は通知領域（タスクトレイ）のアイコンから操作します。

Windows の保護画面が出た場合は、配布元とファイル名を確認し、信頼できるときだけ「詳細情報」から実行してください。

## はじめて使う

1. `PrintScreen` で撮りたい範囲をドラッグします。保存した画像はワークスペースの一覧に表示されます。
2. 画面を録画するときは、ワークスペースの赤い録画ボタンを押し、範囲を決めてから開始します。録画中に停止すると動画が保存されます。
3. 一覧の画像を選んで編集できます。複数画像を選んで右クリックすると、一括変換や PDF 作成ができます。画像1枚の右クリックから OCR で文字を抽出できます。
4. 画像・動画の既定の保存先は Windows の「ピクチャ」内の `PicoPin` です。見つからないときはトレイメニューから保存フォルダを開いてください。

| 操作 | 既定のキー |
|---|---|
| 範囲を撮影 | `PrintScreen` |
| 前回の範囲を撮影 | `Shift + PrintScreen` |
| 画面録画を開始・停止 | `Ctrl + Alt + Shift + R` |
| 前回録画した範囲で録画 | `Ctrl + Alt + Shift + L` |

キーは設定で変更できます。`PrintScreen` が Windows の切り取り機能に割り当てられている場合は、PicoPin が利用可能な代替キーを案内します。

録画の保存倍率は動画ファイルの大きさを変えます。OCR は元画像の文字が小さい、ぼけているなどの場合に読み違えることがあるため、重要な文字は元画像と照合してください。

## 更新・動作環境

トレイアイコンを右クリックして「更新を確認」を選ぶと、更新を確認できます。Windows 10 / 11（64-bit）に対応し、追加のランタイムは不要です。
